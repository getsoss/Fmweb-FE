
# 보유비중 증가/감소

20260812 Wed 2151 최초 작성.

- 세력 유관
- 날짜 유관
- 점수 내림차순

Windows 세력모니터 프로그램의 SearchUserControl.xaml의 위에서 네 번째에 있는 버튼이다.

SearchUserControl.xaml.cs에 버튼의 동작이 정의되어 있다.

시작 날짜와 끝 날짜에서 선택한 세력들의 HAVE를 모두 합한다. 끝 날짜 HAVE에서 시작 날짜 HAVE를 뺀 값이 점수다. 이때 보유비중 "감소"를 검색했을 경우 점수에 -1을 곱해준다. 점수가 0보다 클 경우 검색 결과에 노출된다.
