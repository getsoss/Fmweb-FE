Windows 세력모니터 프로그램의 SearchUserControl.xaml의 맨 밑에 있는 버튼이다.

SearchUserControl.xaml.cs에 버튼의 동작이 정의되어 있다.

좌측에 있는 개미 분석 탭에서 주가, 개미지수, 평균매입단가, 수익률, 고수관심도 옆에 있는 두 체크 박스를 이용해 U 또는 D 또는 "아무것도 선택 안 함"을 각각 선택할 수 있다. 이를 통해 검색 결과를 필터링한다.

이 문서에서 함수 RANK를 다음과 같이 정의한다:

```
RANK는 원소끼리 비교 가능한 배열을 받으면 거기에 순위를 매겨서 반환을 한다.
예를 들어 [1.2, 3.4, 5.6, 3.4, 7.8]를 인수 값으로 넣어주면
[0, 1, 3, 1, 4]를 반환한다.
```

모든 종목에 대해 점수를 구하는 의사 코드는 다음과 같다. 어떤 기준에 대하여 U에 해당하는 동작이 있다면, D를 선택할 때 정반대로 한다고 보면 된다.

```csharp
int[] arr_score = new int[(종목 수)]; // 종목의 점수를 모두 0으로 초기화한다.

double[] arr_fluc = new double[(종목 수)]; // 모든 종목의 시작 날짜와 끝 날짜 사이 등락률 fluc을 구한다. 수학적으로 말하면 (끝 날짜 종가) / (시작 날짜 종가) - 1 이다.

int[] arr_flucrank = new int[(종목 수)]; // RANK((모든 종목의 fluc을 담은 배열)) 을 구한다.

// 주가 U인 경우, fluc이 0 이하일 경우 검색 결과에서 제외시킨다.
// 주가 U인 경우, arr_flucrank를 모두 arr_score에 더한다.

long[] arr_diff_n_acc = new long[(종목 수)]; // 모든 종목의 시작 날짜와 끝 날짜 간의 "키움 보유종목통계"의 "보유계좌수" 차이를 구한다.

// "개미지수"도 "주가"와 같이 한다.

double[] arr_diff_avg_price = new double[(종목 수)]; // 모든 종목의 시작 날짜와 끝 날짜 간의 "키움 보유종목통계"의 "평균매수가" 등락률을 구한다. 등락률은 위에 두 가격을 이용해 등락률 구한 것처럼 똑같이 한다.

// "평균매입단가"도 "주가"와 같이 한다.

// "수익률"은 "키움 보유종목통계"의 "보유계좌수익률" 차를 기준으로 검색한다. 즉 수익률에서 수익률을 그대로 산술적으로 빼준다. 그러고나서 "주가"와 같이 한다.

/*
"고수관심도"는 키움증권 영웅문4의 "[4196] 수익률상위고객 매매 상세 현황 (통합)"에서 Excel로 저장 버튼을 눌러

매매 상세,,,현재가,,,,,매매내역,,,보유현황,,,
순위,종목코드,종목명,현재가,전일대비,,등락률,거래량,매수수량,매도수량,순매매수량,계좌수,수량,평균 매입가,수익률

와 같은 CSV 헤더를 얻을 수 있는데, 여기서 끝 날짜와 시작 날짜 간의 "계좌수" 차를 기준으로 검색한다. 그리고나서 "주가"와 같이 한다.
*/

```


만약 어떤 기준에 대해 U도 D도 선택하지 않았다면 모든 종목을 그대로 pass한다. 즉 기본적으로 모든 종목이 검색 결과에 노출되고, 필터링되는 종목들만 제외시키면 된다.
