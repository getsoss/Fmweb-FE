
# 수익률 상위/하위

20260812 Wed 최초 작성.

SearchUserControl.xaml의 최상단에 있는 버튼이다.

SearchUserControl.xaml.cs에 버튼의 동작이 정의되어 있다.

키움증권의 HTS(Home Trading System)인 Windows 프로그램 "영웅문4"를 실전투자 환경에서 접속하면 "\[1331\] 키움 보유종목통계 (종합)" 이라는 창을 띄울 수 있다.

그 창을 우클릭한 후 "엑셀로 저장..." 버튼을 누르면 아래와 같은 csv 파일이 저장된다.

```
종목코드,순위,종목명,현재가,전일비,,등락률,보유계좌수,평균매수가,보유계좌수익률
'005930,"1",삼성전자,"258,500",▲,"19,000","+7.93","1,477,454","960,066","-75.12"
'000660,"2",SK하이닉스,"1,524,000",▲,"99,000","+6.95","685,137","1,434,855","-0.92"
```

이때 보유계좌수익률이 이 수익률 상위/하위 검색 버튼의 점수가 된다.

보유계좌수익률을 구하는 날짜는 검색 날짜 범위의 가장 최근 날로 정한다.

별도의 노출 기준은 없다. 따라서 모든 종목이 다 검색 결과에 노출된다.

상위는 점수 내림차순으로 정렬하여 보여주고, 하위는 그 반대로 보여준다.
