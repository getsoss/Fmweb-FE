class Jongmok은 class FmRepository에서 "SELECT 종목코드,종목명,결산월,액면가,자본금,상장주식,유통주식,유통비율,상장일
FROM opt10001" 에 의해 row를 받아올 때 사용합니다.

각 멤버에 대응하는 SQL column명은 다음과 같습니다:
Jmcode: 종목코드
Jmname: 종목명
ReportMonth: 결산월
FaceValue: 액면가
Capital: 자본금
ListedStock: 상장주식
OutstandingStock: 유통주식
OutstandingRatio: 유통비율
ListDate: 상장일
