## 참고 자료와 해석

- `수정042.pptx` 1쪽: 영향력 수직축 0~100% → 0~50%.
- `수정044-차트수정.pptx` 1~2쪽: 공간 확보를 위한 차트 표시 선택. 같은 번호의 PDF는 저장소에 없어 PPTX 원본을 확인함.
- `수정004.pdf` 2쪽: 상태 셀에 U·등락률·색을 함께 표시하는 구조. 구판 PDF의 예시 색보다 최신 엑셀 `알람색` 시트를 우선함.
- `260124 세력모니터 web 기획안.pptx` 37~39쪽: 마우스로 알람가격 설정, 알람가격 기준 3% 간격 10단계 색상, U 표시.
- `수정011.pdf` 1쪽: 주가 차트 우클릭 알람가격 입력·삭제 동작 확인.
- `APIDOC_v11.6.0.md` 1·18번 및 GitHub 이슈 #8·#9: 일봉과 종목정보 API, 알람가격 대비 등락률, U 표시 계약.
- **`수정037-1` 원본 파일은 저장소에 없음.** 따라서 해당 문서 자체의 추가 요구사항은 확인하지 못했으며, 26번은 위에 명시한 확인 가능 범위의 개선 내역임.
- 알람색 표에는 경계 부등호가 없어 표의 하락폭을 각 구간의 상한(포함)으로 해석함. 하락폭은 `(알람가격 - 현재가) / 알람가격 × 100`이며, 반올림 전 값으로 색을 결정하고 표시 수치만 소수점 한 자리까지 반올림함.

## 28번 BE 연동 요청

- `/jminfo`와 같은 전종목 일괄 응답에 **10일 이동평균 상승 추세 여부** 제공 필요.
- 상승 판정 기준(예: SMA10 전일 대비 상승인지, 연속 상승인지)과 응답 필드 이름 확정 필요. `ma10_up`은 제안이며 현재 API에 존재한다고 가정하지 않음.
- 현재 이슈 #9는 `ma20_up`을 U 표시 기준으로 명시하므로 FE에서 이 값을 임의로 10일선으로 재해석하지 않음.
- 종목별 캔들을 수천 번 조회하여 FE에서 전종목 추세를 별도로 계산하는 방식은 사용하지 않음. `/api/stocks/{ticker}`는 여러 차트 계열을 함께 조회하므로 그 경로를 전종목에 반복 호출하면 요청량이 더 증가함.

## 검증

- 프로덕션 빌드 및 타입 검사 통과.
- API 회귀 테스트 12개 통과.
- E2E 54개 통과: 10단계 알람색·경계값, 주·월봉 보조 차트 숨김/복원, 검색조건 초기화 및 기존 기능 회귀 검증.
- 실행 중인 개발 서버와 충돌하지 않도록 동일 소스를 별도 디렉터리에 복사해 프로덕션 빌드·E2E 실행. 앱·공개 자산·테스트 파일의 해시가 원본과 동일함을 확인.
- 2,556개 종목 입력 Event Timing 최대 보고값 40ms(50ms 미만) 유지.
- 브라우저 테스트는 모의 API로 검증하며 실제 계정의 운영 서버 데이터까지 검증한 결과는 아님.
- 원본 엑셀의 상태값은 변경하지 않음.
